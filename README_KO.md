# Bithumb Auto Trader — 1차 모의매매 버전

## 현재 제공 기능
- 빗썸 공개 API로 원화마켓 목록, 현재가, 5분봉 조회
- 거래대금 상위 종목을 대상으로 간단한 추세/거래량 필터 적용
- 50만 원 가상 원금, 1회 10만 원, 최대 2종목 모의매매
- 익절 +1.2%, 손절 -0.8% 기준의 가상 매도
- 스마트폰 브라우저에서 볼 수 있는 Streamlit 화면 (15초 자동 갱신)

## 중요: 실거래 기능은 포함하지 않았습니다
이 버전은 Private API에 연결하지 않으며 실제 주문을 전송하지 않습니다.
전략 검증, 수수료/슬리피지 반영, 영속 저장, 주문 중복 방지, 체결 확인,
재시작 복구, 장애 감시가 추가되기 전에는 실거래로 사용하면 안 됩니다.

## PC에서 실행
1. Python 3.10 이상 설치
2. 압축을 푼 폴더에서 터미널 실행
3. 아래 명령 실행

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 표시되는 주소로 접속합니다.

## 스마트폰에서 보기
PC와 스마트폰이 같은 Wi-Fi에 연결된 상태에서 아래처럼 실행할 수 있습니다.

```bash
streamlit run app.py --server.address 0.0.0.0
```

PC에 표시된 로컬 네트워크 주소의 8501 포트로 스마트폰 브라우저에서 접속합니다.
공용 인터넷에 포트를 직접 노출하지 마세요. 외부 접속은 인증과 HTTPS가 적용된
호스팅/터널 구성을 별도로 해야 합니다.

## 무료/저비용 운영에 대한 현실적인 안내
무료 호스팅은 수면(sleep), 재시작, 실행시간 제한이 있을 수 있어 24시간 실거래용으로
보장할 수 없습니다. 우선 로컬 PC 또는 무료 호스팅에서 모의매매만 검증하세요.
상시 운용이 필요해지면 비용과 가용성을 비교해 서버를 선택해야 합니다.
